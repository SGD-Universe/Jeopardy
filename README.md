# Jeopardy Game
To open in Unity, use the Unity 2023.2 version.
If you get the following error:
  CS0234: The type or namespace name 'Android' does not exist in the namespace 'Unity' (are you missing an assembly reference?)
then you need to go to Edit > Project Settings
then Player
then select the Android icon below the Cursor Hotspot fields
then deselect Identification > Override Default Package Name

To see the main scene, go to Assets > Scenes > Main (not the folder)

See IntroToCSharp for information about if you're new to or need a refresher in C# & Unity
